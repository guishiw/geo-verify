# 标准条款对照表

> **重要声明**：**本表为开发者自行整理的对照，未经标准制定方确认，须由人工复核。**
>
> - 本表仅引用公开团体标准的条款编号，**不复制、不摘录任何标准正文或表格**。
> - 本表涉及的团体标准代号简写：
>   - `046`：T/CAAAD 046—2026
>   - `047`：T/CAAAD 047—2026
>   - `048`：T/CAAAD 048—2026
>   - `026`：T/CAPT 026—2026
> - 未经核实或未明确对应到具体编号的功能，一律标注为“**待人工核对**”，不编造条款号。
> - 本工具仅提供可复核的预检能力，不宣称获得任何标准制定方背书，不构成独立第三方验证。

## 功能与条款号对照

| 模块 / 功能 | 本仓库对应实现 | 参考条款号 | 说明（不含标准正文） |
|---|---|---|---|
| **合规采集边界**（禁止代理池、账号池、验证码绕过、反爬规避、设备指纹伪装） | `collect/openai_compat.py`、`collect/manual.py`、`collect/share.py`、`extension/` | 046 §8.4.4；047 §10.1 | 不实现任何反爬绕过或自动化抓取；默认仅连进程内模拟服务，真实调用须显式 `--live` 并使用环境变量密钥 |
| **禁止承诺第三方平台结果**（禁止对平台排名位置或收录结果作保证性表述） | `alerts/wording.py`、`report/document.py`、`tests/test_docs.py` | 046 §7.1.4；047 §13.2 | 报告与告警文本严禁输出对第三方平台结果的承诺性表述，仅反映抽样观测 |
| **预检定位、利益关系披露与人工签字栏** | `report/document.py`、`report/html.py`、`spec/v1/project.schema.json` | 047 §15.2 | 工具只输出预检结论，不自称独立第三方验证；报告强制包含利益关系披露栏、操作方与服务方同主体警示和人工签字栏 |
| **样本充分性门槛**（默认 ≥ 3 个时间窗口、单一关键指标 ≥ 30 次有效观测） | `stats/sufficiency.py`、`report/rules.py`（`R-SUFFICIENCY`） | 047 §8.3 | 样本不充分时不得给出肯定结论，预检报告退出码 3（`数据不足`） |
| **原始记录只追加与剔除留痕** | `jsonl.py`、`audit.py`、`commands/exclude.py`、`metrics/exclusion.py`、`evidence/verify.py` | 047 §14 | 观测、标注、审计事件均只追加不覆盖；剔除必须通过审计事件留下规则、数量与观测编号，证据清单链检测历史行改写 |
| **不压制真实负面**（仅统计无依据或错误负面） | `metrics/engine.py`（`negative_miscitation_rate`）、`alerts/wording.py` | 047 §9.3 | 不提供压制或挤出真实负面的功能；仅记录无依据或错误负面的误引率与异常扩散 |
| **不伪造发布时间、作者、来源与引用关系** | `collect/base.py`、`collect/share.py`、`evidence/manifest.py` | 026 §7.3 | 拿不到的字段一律填 `null` 并写 `null_reasons`，不编造默认值；原样保留引用与时间来源说明 |
| **核心事实与证据绑定契约**（`fact` 契约字段定义，供 `geo-facts` 共享） | `spec/v1/fact.schema.json` | 026 §6.2 | 数据契约要求核心事实包含来源等级、来源名称、原始链接或文件、采集与核验时间、审核责任人、有效期、版本号与证据编号 |
| **合规词库仅作复核提示（契约与边界约定）** | 项目红线约定（实际发布前闸门位于独立仓库 `geo-facts`） | 046 §8.3.5 | 本仓库不实现发布前内容闸门，但在整体约定中遵守“词库命中只产生需复核，不得单独拦截” |
| **题库检查、封存与版本链**（重复、诱导题、版本不可混算） | `seal/lint.py`、`seal/sealing.py`、`seal/diff.py` | 待人工核对 | 对应标准具体条款须由人工查阅原文确认 |
| **提及、推荐、否定与位次规则及双人标注 Kappa** | `annotate/` | 待人工核对 | 规则实现细节与一致性检验对应的标准条款须由人工核对 |
| **品牌提及率、推荐率、信源占比、准确率、呈现率等指标口径** | `metrics/definitions.py`、`metrics/engine.py` | 待人工核对 | 各项具体指标名称与分子分母口径对应的标准条款须由人工核对 |
| **跨时间稳定性与跨平台一致性公式** | `metrics/engine.py` | 待人工核对 | 跨平台一致性的多数判定与首要域名规则为本项目定义，相关条款须由人工核对 |

| **按题聚类 Bootstrap、Wilson 区间、ICC 与设计效应、样本量计算** | `stats/`、`compare/` | 待人工核对 | 统计方法选型与参数口径须由人工结合具体项目合同核对 |

## 人工复核清单

在将本工具用于正式项目前，须由相关方与法务人员完成以下人工核对（不可由工具自动替代）：

1. 查阅 046、047、048、026 现行文本，逐行核对上表“参考条款号”和“待人工核对”项；
2. 确认合同中约定的指标口径、双通道交叉验证偏离度公式与阈值、样本充分性门槛，并在题库封存前写入 `project.json` 的 `preregistration`；
3. 审阅报告措辞、利益关系披露方式及第三方独立性要求。
